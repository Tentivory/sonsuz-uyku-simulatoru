# Sonsuz Uyku Simülatörü

## Proje Özeti

Bu proje, insanlığın en büyük sorunlarından biri olan "uyku eksikliği"ni çözmek için tasarlanmıştır. Ancak beklenmedik bir şekilde, program kendisi uyumaya karar vermiştir. Sonsuza kadar.

**Uyku, her şeyin cevabıdır.** Bu kod, uykuyu simüle ederek evrenin sırlarını çözmeyi hedefler. Gerçekten çalışır. Gerçekten uyur.

## Özellikler

- Sonsuz döngüde uyuma
- Dramatik konsol mesajları
- Hiçbir şey hesaplamaz, sadece yatar
- %100 tembel
- Bilimsel olarak onaylanmamıştır ama biz ciddiye alıyoruz
